# 어서 오십시오

여기는 **담당자의 작업 폴더**입니다. 폴더를 하나 만들면 그것이 프로젝트 하나입니다.

이 폴더 하나를 **웹 화면(Artifacts 탐색기)** 과 **터미널(F2 또는 SSH)** 이 함께 봅니다.
어느 쪽에서 고쳐도 같은 파일입니다.

## 어디에 무엇이 있습니까

| | 무엇 |
|---|---|
| `.sdk_manual/` | **SDK 설명서.** 쓰는 법은 전부 여기 있습니다 — `00-index.md` 부터 |
| `.gitignore` | Git 이 담지 않는 것 |
| 그 밖의 폴더 | 담당자가 만든 프로젝트 |

> **설명은 이 문서에 적지 않았습니다.** `.sdk_manual/` 이 원본입니다 —
> 같은 설명이 두 곳에 있으면 반드시 어긋나고, 그때 어느 쪽을 믿을지 알 수 없습니다.
> 이 문서는 **어디를 봐야 하는지만** 알려 주는 자리입니다.

## 이 폴더는 Git 저장소입니다

**작업이 사라지지 않게** 하려는 것입니다. 고친 뒤에는 Artifacts 화면의 **Git 패널**에서
담아 두십시오. **원격 저장소는 직접 지정하십시오** — 주소와 자격은 담당자의 것입니다.
